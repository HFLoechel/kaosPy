kaospy documentation
====================

PyKaos is a Python package for Chaos Game Representation (CGR),
Frequency Chaos Game Representation (FCGR), and related sequence
analysis methods.

The package provides tools for generating representations from
symbol sequences, including biological sequences such as DNA and
amino acid sequences.
